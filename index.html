1
⭐ วาง Master Context ก่อนเสมอ (สำคัญที่สุด)

ทุกครั้งที่เริ่มเปิดห้องแชทใหม่ใน Claude, ChatGPT หรือ Gemini ให้คัดลอก เล่ม 1 — Prompt 1.1 Master Context ไปวางเป็นคำสั่งแรก เพื่อตั้งค่าให้ AI สวมบทบาทเป็นผู้เชี่ยวชาญการจัดการเรียนรู้ของครูไทย

2
✏️ ปรับแต่งข้อความใน [วงเล็บ]

ใน Prompt จะมีข้อความในเครื่องหมาย [...] เช่น [ชื่อวิชา], [ระดับชั้น], [จำนวนนักเรียน] ให้คุณครูแก้ไขเป็นข้อมูลจริงของห้องเรียนตนเอง

3
🚀 เลือก Prompt ภารกิจที่ต้องการ แล้วสั่งต่อได้เลย

เลือกค้นหา Prompt จาก 3 เล่มตามงานที่ต้องการ นำไปวางต่อในห้องแชทเดิมได้ทันที:

📗 เล่ม 1 ออกแบบแผนฯ / สื่อใบงาน / Active Learning
📘 เล่ม 2 ข้อสอบ HOTS / รูบริก Rubric / ซ่อมเสริม
📙 เล่ม 3 บันทึกข้อความ / โครงการ / วPA / SAR / วิจัย CAR
